# PLUMBER DESIGN — PWA

Визуальный проектировщик систем отопления (BELYAEV_PROJECT). Прогрессивное веб-приложение (PWA): устанавливается на Android и iOS, работает офлайн, данные хранятся локально в браузере.

## Состав

- `index.html` — всё приложение (схема, каталог, ведомость, экспорт) в одном файле
- `manifest.json` — манифест PWA (иконки, режим окна, тема)
- `sw.js` — service worker: кэширование и офлайн-работа
- `icons/` — иконки 192/512 (обычная + maskable) и 180 для iOS

## Установка на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите содержимое папки `pwa/` в корень репозитория (или в ветку `gh-pages`).
3. Репозиторий → **Settings → Pages** → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.
5. Service worker и установка работают только по HTTPS — GitHub Pages это уже даёт.

Либо через GitHub CLI:

```bash
gh repo create termoschema --public --source=. --push
gh api repos/{owner}/{repo}/pages -X POST -f 'source[branch]=main' -f 'source[path]=/'
```

## Установка на устройство

**Android (Chrome):** открыть сайт → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

**iOS (Safari 16.4+):** открыть сайт в Safari → «Поделиться» → «На экран „Домой“» → «Добавить». На рабочем столе откроется в режиме standalone.

## Обновление версии

При изменении `index.html` повысьте `CACHE` в начале `sw.js` (`v2`, `v3`…), чтобы клиенты получили свежую версию.

## Хранение данных

Проекты сохраняются в `localStorage` браузера устройства («Сохранить файл» — экспорт в JSON для переноса на другое устройство).
